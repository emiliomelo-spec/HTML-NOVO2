O que é uma API?

API significa Application Programming Interface. De forma simples, uma API permite que diferentes sistemas se comuniquem e troquem informações.

Imagine um restaurante Pense na API como um garçom:

  • Você → faz um pedido.
  • Garçom → leva o pedido para a cozinha.
  • Cozinha → prepara o pedido.
  • Garçom → entrega a resposta.

Com uma API acontece algo parecido:

Aplicativo → API → Servidor → API → Aplicativo

Exemplos de APIs

Você provavelmente já usa APIs sem perceber:

  • 🌤️ Aplicativos de previsão do tempo.
  • Aplicativos de mapas.
  • Sistemas de pagamento.
  • Login com Google ou Facebook.
  • Lojas virtuais.

Como funciona?

1.Requisição: um sistema pede alguma informação.

2. Processamento: a API recebe e encaminha o pedido.

3. Resposta: o sistema recebe o resultado.

Exemplo:

Aplicativo: "Qual a temperatura hoje?" API: "30°C e ensolarado."

Em uma frase

API é uma ponte que permite que diferentes sistemas "conversem" entre si.
